# 《Automa 自学者参考手册》

这是一个面向 Automa 初学者和进阶使用者的静态网页手册，内容围绕网页自动化流程中最常见的问题展开。

## 内容简介

- 元素定位基础
- XPath 与 CSS Selector 写法
- iframe 与多层 iframe 处理
- 输入失败、点击失败等常见问题排查
- Shadow DOM、动态页面和调试方法
- 常用流程模板与速查示例
